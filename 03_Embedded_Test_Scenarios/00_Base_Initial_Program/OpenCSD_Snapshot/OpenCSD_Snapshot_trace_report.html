The head of every capture is unsynchronised. The ETM emits its alignment-sync pattern only once per TRCSYNCPR period, so a capture started at an arbitrary instant must wait up to a full period before the decoder can lock on. Those bytes are valid trace data that cannot be interpreted without a preceding sync point — not data the logic analyser failed to record. Lower TRCSYNCPR to shorten this head, at the cost of trace-port bandwidth.
