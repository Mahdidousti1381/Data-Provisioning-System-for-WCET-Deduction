# ساختار پایان‌نامه کارشناسی مهندسی برق — دانشگاه تهران

**عنوان پروژه:** طراحی سیستم تأمین داده جهت استنتاج WCET  
**دانشجو:** محمد مهدی دوست محمدی (شماره دانشجویی: ۸۱۰۱۰۰۱۴۲)  
**استاد راهنما:** دکتر مهدی کارگهی  
**دانشکده:** مهندسی برق و کامپیوتر، دانشکدگان فنی، دانشگاه تهران  
**تاریخ تحویل:** شهریور ۱۴۰۵  

---

## 📁 ساختار پوشه‌بندی پروژه

```text
Thesis/
│
├── main.tex                  # فایل ریشه و مستر پایان‌نامه (شامل فراخوانی‌ها و چینش ساختار)
├── preamble.tex              # تنظیمات بسته‌ها، حاشیه‌ها، کادربندی صفحه، قلم‌ها و ماکروها
├── references.bib            # بانک مراجع علمی و مقالات در قالب استاندارد BibTeX
├── build.bat                 # اسکریپت کامپایل خودکار و سریع با یک کلیک (XeLaTeX + BibTeX)
│
├── frontmatter/              # صفحات آغازین و ساختار اداری دانشگاه تهران
│   ├── cover-fa.tex          # روی جلد فارسی با لوگوی رسمی دانشگاه تهران و قلم تیتر
│   ├── commitment.tex        # تعهدنامه رسمی اصالت اثر مصوب دانشکدگان فنی
│   ├── dedication.tex        # صفحه تقدیم و سپاسگزاری
│   ├── abstract-fa.tex       # چکیده فارسی و واژگان کلیدی
│   └── cover-en.tex          # روی جلد انگلیسی (پشت جلد پایان‌نامه)
│
├── chapters/                 # فصول اصلی پایان‌نامه (هر فصل در یک فایل مجزا)
│   ├── ch1-intro.tex         # فصل ۱: مقدمه و بیان مسئله
│   ├── ch2-background.tex    # فصل ۲: مفاهیم پایه و پیشینه پژوهش
│   ├── ch3-architecture.tex  # فصل ۳: معماری کلان سامانه
│   ├── ch4-hardware.tex      # فصل ۴: طراحی و پیاده‌سازی سخت‌افزار
│   ├── ch5-firmware-etm.tex  # فصل ۵: پیکربندی ETMv4 و Firmware
│   ├── ch6-decoding.tex      # فصل ۶: پردازش و رمزگشایی ترِیس
│   ├── ch7-evaluation.tex    # فصل ۷: ارزیابی تجربی و نتایج
│   └── ch8-conclusion.tex    # فصل ۸: نتیجه‌گیری و کارهای آینده
│
└── figures/                  # پوشه تصاویر، لوگوها و نمودارها
    ├── ut_logo.png           # لوگوی دانشگاه تهران
    ├── ece_logo.jpg          # لوگوی دانشکده برق و کامپیوتر
    └── ...                   # نمودارها و تصاویر سخت‌افزار
```

## ⚙️ مشخصات و استانداردهای اعمال‌شده

1. **قلم‌ها (Fonts):**
   * متن اصلی: `B Nazanin` با ضریب مقیاس ۱.۱
   * عناوین و تیترها: `B Titr`
   * متون انگلیسی و نمادهای ریاضی: `Times New Roman`
   * قلم‌های ثانویه: `B Zar` و `B Mitra`
2. **کادربندی و حاشیه‌ها:**
   * حاشیه‌ها منطبق بر گزارش مصوب `PSA1`: بالا ۳۰ میلی‌متر، پایین ۲۵.۴ میلی‌متر، چپ ۲۲.۲ میلی‌متر، راست ۲۴.۳ میلی‌متر.
   * کادربندی ظریف خاکستری دور صفحات با بسته `eso-pic` و `tikz`.
3. **موتور کامپایل:**
   * **XeLaTeX** به دلیل سازگاری کامل با بسته زی‌پرشین (`xepersian`).

## 🚀 روش‌های کامپایل و تولید فایل PDF

### روش ۱: استفاده از اسکریپت تک‌کلیکی `build.bat`
کافیست در محیط پوشه `Thesis` فایل `build.bat` را اجرا کنید یا در خط فرمان بنویسید:
```cmd
build.bat
```

### روش ۲: کامپایل از طریق افزونه LaTeX Workshop در VS Code
با نصب افزونه **LaTeX Workshop** در VS Code، تنظیمات آماده‌شده در مسیر `.vscode/settings.json` به صورت خودکار پروژه را با رسیپی `xelatex -> bibtex -> xelatex*2` کامپایل و پیش‌نمایش زنده پی‌دی‌اف را در یک تب نشان می‌دهد.
